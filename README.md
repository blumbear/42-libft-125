# 🧩 Libft

> 42 Project — Re-creating a custom standard C library.

---

## 📘 Description

**Libft** is the first foundational project at [42](https://42.fr/).  
The goal is to rebuild a selection of essential functions from the C standard library, along with additional utility functions, to gain a deep understanding of low-level programming and memory management.

This library will later serve as a base for many other 42 projects.

---

## 🧠 Learning Objectives

- Master the fundamentals of **C programming**
- Understand **memory allocation and management** (`malloc`, `free`)
- Manipulate **strings**, **arrays**, and **linked lists**
- Write clean and consistent code following the **42 Norm**
- Create a **reusable and reliable library**
